# 🐍 Professional Snake Game

A feature-rich Snake Game built using Python and Pygame, featuring custom graphics, sound effects, multiple levels, and difficulty settings.

🎮 Features

- Classic Snake gameplay with keyboard controls
- 10 progressive game levels
- Custom snake, food, and background graphics
- Three difficulty settings: Low, Medium, and Hard
- Score and high-score display
- Bonus food for extra points
- Sound effects with an On/Off option
- Interactive main menu and settings menu
- Pause and resume functionality
- Fullscreen support
- Game Over screen with a Play Again option

🛠️ Technologies Used

- Python
- Pygame
- PyInstaller

📂 Project Files

- `snake_game.py` — Main game source code
- `snake_game.spec` — PyInstaller configuration
- `snake_head.png` — Snake head image
- `snake_body.png` — Snake body image
- `food.png` — Food image
- `bonus_food.png` — Bonus food image
- `trophy.png` — Trophy image
- `fruit_icon.png` — Fruit icon
- `snake_menu.png` — Menu image
- `background_level_1.png` to `background_level_10.png` — Level backgrounds
- `eat_sound.wav` — Eating sound effect
- `game_over.wav` — Game over sound effect
- `PressStart2P.ttf` — Game font

⚙️ Installation and Setup

1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

2. Clone the Repository

```bash
git clone https://github.com/kumarharshdeep/Professional-Snake-Game.git
```

3. Open the Project Folder

```bash
cd Professional-Snake-Game
```

4. Install Pygame

```bash
python -m pip install pygame
```

5. Run the Game

```bash
python snake_game.py
```

🎯 Controls

| Key | Action |
|---|---|
| Arrow Keys | Move the snake |
| Esc | Pause or resume the game |
| F11 | Toggle fullscreen |

🏆 Level Progression

The game includes 10 levels with different backgrounds, colors, and obstacles.
